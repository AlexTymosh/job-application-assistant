# User flows

## Setup

1. Confirm the app data folder.
2. Review setup diagnostics.
3. Configure settings and export formats.
4. Store an OpenAI API key through the keyring boundary when real AI mode is enabled.

## Resume builder

1. Create a person profile.
2. Add private contact details.
3. Create one or more resumes for the profile.
4. Add sections, blocks, and bullets.
5. Add facts and evidence.
6. Configure AI edit permissions.

## Application tailoring

1. Create an application with a profile, resume, and job text.
2. Extract requirements.
3. Run tailoring.
4. Review before/after proposals.
5. Accept or reject every proposal.
6. Create an approved snapshot.
7. Export enabled formats.
8. Generate and review a cover letter.
